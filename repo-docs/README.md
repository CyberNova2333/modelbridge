客户端希望用同一种聊天协议访问不同供应商，网关却必须把调用权限、模型选择和上游凭据分开处理。本指南跟随一次聊天请求，解释它怎样选中账号并返回普通或流式结果。

## 覆盖范围

覆盖 OpenAI Chat Completions 输入、调用密钥、模型解析、通用上游选择和错误/流返回边界。管理界面、完整 Durable Object 配置生命周期、用量查询、Antigravity OAuth、嵌入及所有协议组合不逐段展开。当前主要实现和测试含未提交改动，源码可读不等于已经生产验收。

本包采用 Lite 加代码地图：主流程先建立行为模型，地图用于定位，证据页用于审计。源码和脚本是实现事实的依据；旧文档或测试文件的存在不代表本轮实跑通过。
