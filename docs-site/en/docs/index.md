# Quick Start

Unify disparate model providers behind a single robust, observable, and fail-safe API endpoint.

## Core Problems Solved

- **Pain Point 1**: Vendor lock-in and disparate client SDKs across AI providers.
- **Pain Point 2**: Upstream rate limits and sporadic service degradations disrupting critical applications.
- **Pain Point 3**: Inconsistent streaming formats and lack of centralized observability.

---

## Prerequisites

Node.js 20+, TypeScript 5+, pnpm 12.6.0.

---

## Quick Installation & Launch

```bash
# 1. Install project dependencies
pnpm install

# 2. Run local tests and verification
pnpm test
```
