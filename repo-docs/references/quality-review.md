## 可理解性复核

主流程先说明一个可观察请求，再引入鉴权、目标与账号；源码名称放在阶段解释后。代码地图用于找责任，概念页分别说明配置、协议、资源和多平台机制。根中英 README 负责部署和接入，指南保持中文，术语表用于消除概念歧义。

反证检查（Falsifying check）：若读者仍把模型列表当成权限保证、把三账号预算当成最多三次 HTTP 请求、或把模拟测试当成真实账单验收，应重新检查对应页面，而不是增加一张笼统“兼容”表。

下一位读者可能问（Next reader question）：某个具体模型的图像、思考、工具和多轮回放能否用于自己的客户端？本指南给出检查入口和已知拒绝边界，不能替代该组合的真实账号验收。

## 剩余风险与范围

文档不证明供应商未来字段、计费或权限保持不变；默认免费模型目录也不是实时价格承诺。生产磁盘与恢复、HTTPS、云端流取消、OAuth 项目权限、模型输出质量和计费仍需在单独授权的验收中确认。SQLite 版本不承诺多机高可用。

文档站保留 VitePress 默认主题；已知开发搜索索引需重启刷新。构建成功证明页面可生成，不证明 Worker 业务或云端工作流已经通过。源码依据和排除范围见[两遍调查记录](source-evidence.md)，实际命令结果见[指南同步记录](../change-log.md)。
